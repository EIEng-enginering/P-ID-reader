# Research evidence and official resources, accessed 2026-11-09

This is a verification-oriented reference list, not a permission to copy restricted manuals or standards into Claude. Vendor specifications change: pin model versions, code and dependency hashes. Each research entry is a claim limited to what the cited source actually establishes.

1. DEXPI official release (30 Sep 2026), 'DEXPI 2.0.1 Specification Published - The Update Replacing DEXPI 2.0': https://dexpi.org/dexpi-2-0-1-specification-published-the-update-replacing-dexpi-2-0/ . **VERIFIED** DEXPI 2.0.1 replaced 2.0 and updated plant/process model references; licence described as CC-BY-4.0 with attribution.
2. DEXPI specifications index: https://dexpi.org/specifications/ . **VERIFIED** provides open vendor-neutral specification, DEXPI XML serialization and latest 2.0.1. Inspect actual XSD and validate generated output; schema compliance cannot be inferred from model field labels.
3. DEXPI XML reference: https://dexpi.gitlab.io/-/Specification/-/jobs/16843427246/artifacts/src/.build/html/html/basics/metamodel_and_exchange_format.html . **VERIFIED** DEXPI XML root is `Model` in 2.0.1 documentation, and XSD/examples provided; verify stable release artifacts before use.
4. pypdfium2 official PyPI: https://pypi.org/project/pypdfium2/ . **VERIFIED** Python binding is Apache-2.0/BSD-3-Clause, PDFium BSD-style with other native dependency licences; its wheel licences must be bundled. This is the existing rendering option.
5. PyMuPDF official licence: https://pymupdf.io/licensing . **VERIFIED** AGPL/commercial dual licensing; do not add to permissively distributed private desktop program without a compatible approval.
6. RapidOCR official docs, legacy retirement notice: https://rapidai.github.io/RapidOCRDocs/main/en/install_usage/rapidocr/install/ . **VERIFIED** unified `rapidocr` is succeeding the per-engine packages; don't assume drop-in compatibility with installed 1.4.4.
7. RapidOCR model licences: https://rapidai.github.io/RapidOCRDocs/main/en/model_licenses/ . **VERIFIED** particular listed models are Apache-2.0 and provenance/weight SHA documented, but individual other models require separate audit.
8. RapidOCR model list: https://rapidai.github.io/RapidOCRDocs/main/en/model_list/ . **VERIFIED** PP-OCRv6 tiny/small/medium and different language routes exist, conditional on version/engine; quality/speed must be benchmarked in this actual Windows project.
9. Automated Digitization of Engineering Schematics (Electronics, 2026), https://doi.org/10.3390/electronics15173785 . **VERIFIED** research explores tiled detection, OCR, text-to-symbol association, 107-class P&ID detection mAP@50 ~0.91 within its dataset, **BUT** explicitly omits connecting lines and flow direction. This is not evidence that a complete P&ID reconstruction engine exists off the shelf.
10. ANSI/ISA-5.1-2024 official scope: https://www.isa.org/standards-and-publications/isa-standards/isa-standards-committees/isa5-1 . **VERIFIED** current instrumentation control symbol/identification reference; source materials are rights-restricted. ISA product page https://www.isa.org/products/ansi-isa-5-1-2024-instrumentation-and-control-symb explicitly prohibits entry of ISA IP into AI tools without permission. Do not reproduce.
11. ISO 10628-1:2014 official: https://www.iso.org/cms/%20render/live/en/sites/isoorg/contents/data/standard/05/18/51840.html . **VERIFIED** remains current after 2026 review, provides diagram classification/content/representation; no assumption of freely redistributable graphical content.
12. NetworkX shortest path documentation: https://networkx.org/documentation/latest/reference/algorithms/shortest_paths.html . **VERIFIED** standard algorithms for sparse graph queries and complexity; using existing algorithms on typed proposed topology is distinct from engineering verification. BSD licensing needs checking for chosen version.

**Use of these sources:** technical concepts/research references. No external web access is required by the shipped runtime. Never upload confidential drawings or full copyrighted standard texts to a third-party AI. New dependency adoption requires an ADR, model licence and actual baseline benchmarks. Distinguish `VERIFIED` public documentation from `UNVERIFIED` hardware claims and proposal defaults.
